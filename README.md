# 🍅 Pomodoro

Лёгкий нативный помодоро-таймер для macOS в каваи-стиле. Без Electron, без веб-обёрток — чистый SwiftUI, бинарник ~1 МБ, почти нулевое потребление ресурсов.

## Возможности

- **Произвольные циклы** — не только классический 25/5: собирай свои цепочки фаз любой длины (`25 работа → 5 перерыв → 20 созвон → 30 обед`), сохраняй как пресеты.
- **Подписи фаз** — каждая фаза может называться по-своему, чтобы было понятно, что сейчас идёт.
- **Меню-бар** — иконка с оставшимся временем и быстрым управлением.
- **Плавающие каваи-оверлеи** — чип-таймер с мордочкой и отдельная панель управления поверх всех окон, включая полноэкранный режим. Перетаскиваются, позиции запоминаются.
- **Уведомления + звук** — нативные баннеры macOS и системный звук при смене фазы (настраивается).
- **Задачи** — список задач с оценкой в помодоро и привязкой сессий.
- **Статистика** — журнал сессий, сводки за день/неделю, экспорт в **CSV** и **XLSX** (генерируется без сторонних зависимостей).
- **Настройки** (Cmd+,) — автопереход между фазами, звук, время в меню-баре, прозрачность оверлея.

## Требования

- macOS 13+
- Xcode (полный) или Command Line Tools

> **Примечание про сборку:** в SDK macOS 27 `@State` стал макросом, чей плагин есть только в полном Xcode. Скрипты сами выбирают Xcode, если он установлен, иначе собирают через Command Line Tools с SDK 26.x.

## Сборка и запуск

```sh
git clone https://github.com/lovinervy/Pomodoro.git
cd Pomodoro

./run.sh          # собрать и запустить (debug)
./run.sh test     # прогнать тесты (34 шт.)

./bundle.sh           # собрать Pomodoro.app (debug)
./bundle.sh release   # релизная сборка
open Pomodoro.app
```

Иконка (`Assets/AppIcon.icns`) генерируется автоматически при сборке бандла — скрипт `Scripts/make_icon.swift` рисует её векторно.

## Готовая сборка

Скачай `Pomodoro-macOS.zip` из раздела [Releases](../../releases), распакуй и перетащи в `/Applications`.

Приложение подписано ad-hoc (без Apple Developer ID), поэтому при первом запуске macOS может показать предупреждение: **Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»**.

## Структура

```
Package.swift           — SwiftPM-пакет (ядро + приложение + тесты)
Sources/
├── PomodoroCore/       — движок таймера, циклы, задачи, статистика, экспорт
│                        (чистая логика, полностью покрыта тестами)
└── Pomodoro/           — SwiftUI-приложение: окна, меню-бар, оверлеи, настройки
Tests/                  — 34 теста (swift-testing)
Scripts/make_icon.swift — генератор иконки
run.sh, bundle.sh       — сборка/запуск/упаковка
```

## Как устроен движок

`TimerEngine` — чистая конечная машина: не планирует таймеры и не трогает часы сам, время приходит снаружи через `tick(now:)`. Поэтому он не накапливает дрейф, корректно переносит «перебор» опоздавшего тика в следующую фазу и не тратит CPU в простое.

## Данные

Всё локально, в `~/Library/Application Support/Pomodoro/`:

- `cycles.json` — пресеты циклов
- `tasks.json` — задачи
- `sessions.jsonl` — журнал сессий (по записи на строку, устойчив к обрывам)
